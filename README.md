# intake-form

Static **Auto Accident Intake** (`form.html`) for GitHub Pages.

- **Live:** https://manumasferral-ops.github.io/intake-form/form.html  
- **Weekly agent:** enable Actions on this repo; `.github/workflows/weekly-intake-review.yml` opens a GitHub issue every Friday as a reminder. In Cursor, use the personal skill `intake-form-weekly-review` (`~/.cursor/skills/intake-form-weekly-review/SKILL.md`) to perform the review and PR changes.
